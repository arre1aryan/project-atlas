## Graphs

### Problems Solved
- **743 — Network Delay Time**

### Concepts / Patterns
- Dijkstra's Algorithm
- Minimum Spanning Tree (MST)
- Prim's Algorithm
- Shortest Path with Constraints
- Priority Queue / Min Heap
- Graph Representation
- Relaxation of Edges
- Handling weighted graphs
- Comparing shortest-path approaches

### Key Takeaways
- **743** → Classic Dijkstra problem for finding the shortest distance from a source to all nodes.
- **1584** → Minimum Spanning Tree problem; solved efficiently using Prim's Algorithm with a min heap.
- **787** → Shortest path with a constraint on the number of stops; requires tracking both cost and stops rather than using standard Dijkstra blindly.
